## Full description (max 4000 chars)

```
Logit is a free, open-source companion app for your self-hosted LubeLogger server. Track fuel, mileage, service and repairs, and get maintenance reminders for every vehicle, right from your phone.

Requires your own LubeLogger server. Logit talks only to the LubeLogger instance you point it at, using an API key you generate there. No account, no cloud service of ours, no ads, no analytics.

YOUR WHOLE GARAGE
• Add, edit and remove vehicles and see their photos
• Distance in kilometres, miles or engine hours

FUEL & MILEAGE TRACKER
• Log fill-ups and odometer readings
• Fuel economy at a glance: average, min, max, distance and cost
• Home-screen shortcuts to add a fuel or odometer entry in one tap

COMPLETE SERVICE HISTORY
• Service, repairs, upgrades, tax, supplies, planner and notes: every record type LubeLogger supports, all editable
• Attach receipts and documents to records

REMINDERS
• LubeLogger's maintenance reminders, sorted by urgency
• Optional background notifications when something is due or overdue

DASHBOARD & CHARTS
• Per-vehicle overview with fuel-economy trends, mileage by month and cost summaries

MADE TO FIT YOU
• Show, hide and reorder record tabs
• Metric or imperial units, light or dark theme
• Phone and tablet layouts
• Available in English, Polish, German, French and Spanish

TRY IT WITHOUT A SERVER
Enter "demo" as the server address and "demodemodemo" as the API key to explore sample vehicles offline.

PRIVACY
Your API key is stored in encrypted, Android Keystore-backed storage and is sent only to the server you configure.

Works with LubeLogger 1.6.9 and 1.7.0. Source code under AGPL-3.0: https://github.com/DoYouHost/logit-for-lubelogger

"LubeLogger" is a project of Hargata Softworks. Logit is an independent, community-built app and is not affiliated with the LubeLogger project.
```
